# OpsPilot Agent

StartupOps Agent is a measured agentic AI system for customer feedback triage.

## Core Workflow

Customer feedback -> issues -> priorities -> tickets -> customer replies -> founder summary -> evaluation -> human approval.

## MVP Scope

Only one workflow:
Customer Feedback Triage.

## Must-have Features

- Intent routing
- Agent planning
- Memory search
- Knowledge search
- Issue extraction
- Issue clustering
- Priority ranking
- Ticket generation
- Customer reply drafting
- Founder summary
- Evaluation layer
- Retry/fallback logic
- Human approval gate
- Agent step timeline
- Benchmark dashboard

## Not in MVP

- Real Jira integration
- Real email sending
- Real Slack integration
- Payments
- Multi-user auth
- Complex file permissions
